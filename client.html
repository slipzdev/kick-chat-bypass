kick-chat-serverside

Server-side Kick chat via Pusher WebSocket - no Puppeteer needed

Not connected
How it works: Your browser connects to the local server via WebSocket. If the server doesn't have the chatroom ID cached, it'll ask your browser to fetch it from kick.com (this works in OBS browser sources which ignore CORS, and in regular browsers if kick.com allows the request). The server then connects to Kick's Pusher WebSocket and forwards chat messages back to you.
